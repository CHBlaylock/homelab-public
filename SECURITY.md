# Security and Public-Repository Policy

This repository is intentionally sanitized.

## Never publish

- Passwords
- API keys
- Tailscale authentication keys
- SSH private keys
- Database credentials
- Recovery codes
- Tokens or cookies
- Private certificates
- Real home network maps when they are not necessary
- Personal identifiers that do not contribute to the technical project

## Public documentation approach

Technical concepts, commands, architecture, troubleshooting methods, and sanitized examples may be documented.

Real IP addresses, usernames, tailnet identifiers, and other home-specific details are replaced with generic descriptions.

The complete operational configuration remains in a separate private repository.
